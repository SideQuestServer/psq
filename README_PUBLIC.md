# PixelSideQuest

A pixel art and Minecraft texture editor in a single, self-contained HTML file.

## Features

- **Pixel Art Editor**: Create and edit pixel art with classic tools (brush, eraser, selection, magic wand, lasso)
- **Vector Tools**: Bezier pen with smart guides for precise vector editing
- **3D Model Support**: Import and edit 3D models from Minecraft (OBJ, BBModel formats)
- **Texture Editing**: Perfect for Minecraft textures, sprites, and tilesets
- **Offline**: Runs entirely in the browser, no server needed
- **Responsive**: Works on desktop and mobile devices

## Download & Use

1. Download `PixelSideQuest.html`
2. Open the file in any modern web browser (Chrome, Firefox, Safari, Edge)
3. Start creating!

**No installation required.** The entire app is contained in a single HTML file.

## Keyboard Shortcuts

- **V** – Selection tool
- **W** – Magic wand (smart select)
- **Q** – Lasso select
- **P** – Bezier pen (vector tool)
- **[** / **]** – Rotate selection by 15°
- **D** – Default tool
- **E** – Eraser

## Tips

- Save your work as PNG or use the app's native save format
- Import 3D models to use as reference or edit directly
- Use the color picker for precise color selection
- Mobile users: swipe to pan, pinch to zoom
